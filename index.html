Side projects

01

TG-Type

macOS 語音輸入工具。它不是一般的 Whisper：一般的語音辨識會把專有名詞聽成別的字，也不知道你是誰、現在在寫什麼。

  • 錄音前先把詞彙送進辨識引擎：手動指定的詞、系統學過的詞、以及從當下畫面抓到的專名，三層合併後當作 ASR 的提示，容易聽錯的名字先固定住
  • 用 macOS Vision 在本機 OCR 前景視窗（中英皆可），再由背景模型蒸餾成關鍵詞與主題，交給文字整理修同音字與術語；同時依前景 App 類別決定輸出格式，聊天視窗給短回覆、其他給段落
  • 每次你手動改過的地方都會被比對出來，通過檢查的術語自動進常用詞庫，下一次錄音就不會再錯
  • 學習不是無條件累積：每 6 小時掃一次，跨兩天出現三次才升級為常駐詞，並保留一成留出樣本評估效果，沒有幫助的詞會被停用
  • 持續打磨操作流程：說完就自動落在你正在打字的地方，快捷鍵、狀態提示與失敗時的退路都做過，讓它在日常工作裡不需要特別配合
02

Kodama

自行設計的 multi-agent 開發系統。早期的定位是身份代理——讓多個 agent 以不同身份分工，把一件事從 issue 推到合併；現在重心移到個人專屬的專案記憶。

  • 記憶層是混合檢索：BM25 加向量、實體圖譜與時間加權，回答問題時先把相關的偏好、決策與工作脈絡撈回來
  • 七個環節各自獨立的 workflow：issue 建立、定性、規劃、開發、審查、收 PR，每環輸出結構化結果給下一環
  • 巡檢 workflow 定期掃描各環的健康指標與回歸基線，由 agent 指出瓶頸並提出改法
  • Discord／Telegram／Slack 通道支援串流回覆與排程推送；WIP 閘門擋住同時開太多工作
03

OMP

我每天在用的 AI 工作環境，由三個各管一件事的專案組成：omp-home 是規則與能力的控制面，cmux-console 讓全機的 session 互相看得見、互相派工，omp-memory 把做過的事變成可以被回想的記憶。

  • 控制面只有一份：跨專案的規則、技能、角色與生命週期 hooks 全部集中，59 個 domain skill 按觸發條件載入，換到別的專案不用重新教一次
  • 常駐 daemon 每 4 秒掃一次全機 session，一個終端面板就看完誰在做什麼；session 之間可以直接傳訊息、把任務派給正空著的那個，也能一次開一批新的
  • 對外是一個帶認證的介面加通道，手機在外面就能盤點現況、開新 session、下指令，人不在電腦前也能把事情推進
  • 記憶不是存檔：從 session 紀錄蒸餾成帶時效的記憶單元（何時知道、何時失效、被什麼取代），分全機通用與單一專案兩種範圍，取用時做全文檢索並依專案與類型加權
  • 每 4 小時結算一份活動摘要（做完什麼、卡在哪）並保留兩週；蒸餾與回想由獨立設定的分身 agent 執行，不佔用我本人的工作 session
04

AI 123

桌面上的個人 Jarvis：用語音跟它聊，它看得見你的畫面、動得了你的電腦，也記得你的個人資料。

  • 語音是雙向的：熱鍵開口說，24kHz 串流即時辨識，回覆直接用語音播出並同步上字幕
  • 真的能操作這台電腦：點擊、拖曳、滾動、打字、開啟 App，並讀取前景視窗與焦點元素來決定往哪裡下手
  • 看得見螢幕：擷取畫面與可存取性資訊作為判斷依據，不只依賴你打出來的字
  • 個人記憶有生命週期：先抽出候選、經確認才寫入，可以取代或刪除，讓它知道你的習慣而不是亂記
