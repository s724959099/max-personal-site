Case 01
TransglobalUS
2023—2026

從全面依賴第三方，逐步收回自己的營運系統

核心流程原本散在 iPipeline、HubSpot 與其他外部服務。不是一次重寫，而是把最重要的資料、流程與服務能力一段一段收回來，最後讓 CRM 與 Workshop 成為公司的工作核心

原本

資料與 workflow 分散在外部工具，業務邏輯難以統一

做法

以 CRM 與 Workshop 承接核心流程，同步建立 AI log inspection、CI code review、human handoff 與驗證節奏

留下

7,000+ Agent、約 9,000 日活使用者、18 人技術團隊與可持續演進的核心平台

Case 02
TG-Type
macOS

輸入不是終點，學習才是

TG-Type 不只是把語音轉成文字或留在本機。它把逐字稿、smart format、選文改寫與個人化學習接成同一條路，目標是減少「明明講完了，還要花時間改回自己的語氣」

原本

一般語音輸入只交出逐字稿，標點、語氣與格式仍要人工重整

做法

依上下文 smart format，並從使用者的修正與偏好中逐步學習

留下

更接近個人表達方式的輸入工具，能把口述內容直接送到正在使用的 App

Case 03
Kodama
Web → Discord

在 Hermes 出現前，先做了一個能成長的 Web 版 agent

Kodama 的第一版是自建 Web agent，後來整合進 Discord。當 Hermes 出現後，它不需要再和 Hermes 做同一件事，於是留下最有價值的部分：讓系統能從互動與資料裡理解個人工作脈絡

原本

想要一個能在 Web 上運作、可以持續累積脈絡的個人 agent

做法

建立 Web 介面、Discord 接點、工作流與資料累積機制

留下

RAG 與 memory 機制，讓後續工具理解偏好、決策與工作 context

Case 04
OMP
Oh My Pi

讓工作可恢復、可委派、可驗證

OMP 是主要的 development harness，不是 OMP Home，也不是 OMP Memory。它把跨專案 rules、skills、hooks、extensions、session recap、worktree、verification 與 delivery 收斂成可以接手的工作系統

原本

AI 開發容易停在單一 session，離開現場就失去進度與上下文

做法

把 worktree、驗證、交付、session recap 與跨專案工作規則做成可重用 harness

留下

能在不同情境接回工作的工程底座，memory 只保存能幫助分身延續工作的脈絡
