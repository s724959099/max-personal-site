01TransglobalUS
核心營運系統

把關鍵 workflow 從第三方工具收回，做成公司自己的核心。

在 TransglobalUS，從 1 人開始建立並帶領 18 人技術團隊，主導自建 CRM 與 Workshop，取代 iPipeline、HubSpot 等多年沿用的第三方平台。CRM 服務 7,000+ agents，Workshop 約有 9,000 位每日使用者。

  • 規模團隊從 1 人擴編至 18 人，建立前後端與 Lead 分工。
  • 判斷AI log triage 區分 true alerts 與 false alerts，撈出未被發現的線上隱患。
  • 交付CI/CD、AI code review 與 human handoff，配合文件化需求與多方 signoff。

HubSpot 單項年訂閱即逾 $100k USD；將成本與資料主權一併收回。

02TG-Type
macOS 語音輸入

輸入不是終點，學習才是。

TG-Type 將 ASR 轉錄、LLM smart format、選取文字重寫與個人化學習接成同一條路；從 corrections 與 preferences 裡持續理解使用者，並把結果送進前景 App。

本機 LLM 優先；LLM 超時時 fallback 回原始轉錄，不掉字。

03Kodama
Web agent

讓 AI 協作記得工作脈絡，而不只是回放聊天。

Kodama 是自行設計的 multi-agent 開發系統：把 workflow 編排、權責隔離與 self-improving 機制放在同一個可持續演進的工具裡，並以 RAG / memory 保存偏好、決策與工作 context。

Web UI、Discord 與 schedule 是接點；真正的價值是讓下一次工作能接得回來。

04OMP · Oh My Pi
開發工具鏈

讓工作可恢復、可委派、可驗證。

OMP 把跨專案 rules、skills、hooks、extensions、session recap、worktree、verification 與 delivery 收斂成一致的工程邊界，讓交付不依賴某個人記得所有步驟。

重點不是把一次任務跑完，而是讓下一個人看懂、接手、重新開始。
